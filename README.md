# GuitarLA - Tienda de Guitarras con React + TypeScript
Aplicación web inspirada en una tienda de guitarras. Permite visualizar productos, agregar artículos al carrito y calcular el total dinámicamente.

# Tecnologías utilizadas
- React  
- TypeScript  
- Vite
